# Product

Objective: authorized voice sample plus script becomes convincing narration,
with problem identification, selective repairs, and polished export.
Local first, open-source intended, replaceable existing inference engines.
Technical controls record user attestation; they cannot prove identity or consent.

Initial scope: bounded CLI synthesis to WAV. Later milestones add longer scripts,
editing, QA, local UI and optional ecosystem integration, in that order.
No foundation-model training, live calls, SaaS, billing, mobile, marketplaces,
mandatory ecosystem dependencies, or unrelated HowlFrame work.
No remote inference until destination, payload, retention and cost are disclosed
and approved. No sample acquisition or cloning without authorization.
