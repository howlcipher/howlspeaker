02

WORKING TODAY

Small tools. Explicit boundaries.

CLI and Python API

Install locally with Python 3.12 or newer. No model weights are bundled. The core package has no runtime dependencies.

validate-voice checks authorized PCM WAV references. export-simulation publishes playable, labelled fixture audio without overwriting files.

Use validate_voice and ExportService from Python. The simulation coordinator has a test-only provider seam.

Read the command and API guide ↗
LOCAL TERMINALNO MODEL DOWNLOAD
# Install the current development branch
git clone --branch feature/wav-export-and-project-page \
  https://github.com/howlcipher/howlspeaker.git
cd howlspeaker
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e .

# Validate a voice you are authorized to use
howlspeaker validate-voice --voice sample.wav \
  --authorized --provenance "My voice; my recording"

# Export existing fixture audio, not speech generation
mkdir -p output
howlspeaker export-simulation --input fixture.wav \
  --output-dir output --name check.wav
[LOCAL]

Permission before processing.

No recordings or scripts are uploaded by these tools. The project page has no file upload, analytics or inference service. Authorization is a user attestation, not proof of identity or consent. Remote inference will require explicit opt-in.
